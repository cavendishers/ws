# 中国省市区三级联动选择器

## 功能特点

✅ **三级联动**：省份 → 城市 → 区县的层级选择  
✅ **多选支持**：每一级都支持多选复选框  
✅ **智能搜索**：支持关键词搜索所有地区  
✅ **美观界面**：现代化深色主题，与系统风格一致  
✅ **响应式设计**：支持桌面和移动设备  
✅ **数据完整**：包含全国所有省市区数据

## 使用方法

### 1. 基本使用

```html
<!-- 引入CSS -->
<link rel="stylesheet" href="{% static 'data_hall/css/region-selector.css' %}">

<!-- 引入JS -->
<script src="{% static 'data_hall/js/region-selector.js' %}"></script>
```

### 2. JavaScript API

```javascript
// 打开地区选择器
window.regionSelector.show([], (selectedCodes, selectedNames) => {
    console.log('选中的地区代码:', selectedCodes);
    console.log('选中的地区名称:', selectedNames);
});

// 带预选项打开
const preselected = ['110000', '310000']; // 北京、上海
window.regionSelector.show(preselected, (codes, names) => {
    // 处理选择结果
});
```

### 3. 在侧边栏中使用

地区选择器已集成到产业链侧边栏的筛选功能中：

```javascript
// 在筛选区域会自动显示地区选择按钮
// 点击后打开三级联动选择器
chainSidebar.openRegionSelector();
```

## 界面说明

### 主界面布局
- **顶部搜索框**：输入关键词搜索所有地区
- **三列布局**：
  - 左列：省份/直辖市列表
  - 中列：选中省份下的城市列表  
  - 右列：选中城市下的区县列表
- **底部操作区**：显示已选数量，重置和确定按钮

### 交互方式
- **复选框**：点击选择/取消选择地区
- **列表项**：点击展开下级地区（省份→城市→区县）
- **搜索**：实时搜索，支持拼音和汉字
- **重置**：清空所有选择
- **确定**：确认选择并关闭

## 数据格式

地区数据采用国家标准行政区划代码：

```json
{
  "86": {
    "110000": "北京市",
    "120000": "天津市",
    "130000": "河北省"
  },
  "110000": {
    "110100": "市辖区"
  },
  "110100": {
    "110101": "东城区",
    "110102": "西城区"
  }
}
```
