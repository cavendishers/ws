# AI聊天助手持久化功能测试指南

## ⚠️ 重要更新说明

**本文档已过时**：`chat-storage.js`文件已被移除，因为现在所有聊天记录都存储在后端MySQL数据库中，通过`AIChatManager`类进行管理。

如需测试聊天功能，请参考：

修复了以下关键错误：

1. **函数名错误**: `showChat` → `restoreChat`
2. **变量名错误**: `aiChatWidget` → `chatWidget`
3. **状态持久化缺失**: 添加了聊天窗口展开/折叠状态的持久化

5. **最小化位置逻辑**: 修复了最小化行为，默认折叠到右下角，支持拖拽位置记忆

7. **初始化逻辑优化**: 避免不必要的折叠动画闪烁
8. **脉冲动画优化**: 只在首次访问时显示欢迎脉冲动画
9. **错误处理优化**: 添加了更好的异常处理和降级方案

## 测试步骤

### 1. 基础功能测试

1. **启动应用**:
   ```bash
   python manage.py runserver
   ```

2. **访问Shell页面**:
   - 打开浏览器访问: `http://localhost:8000/shell/`
   - 确认页面加载正常，无JavaScript错误

3. **检查存储初始化**:
   - 打开浏览器开发工具（F12）
   - 在Console中输入: `window.chatStorage`
   - 应该显示存储管理器对象，而不是 `undefined`

### 2. 消息持久化测试

1. **发送测试消息**:
   - 点击聊天助手按钮展开聊天窗口
   - 发送几条测试消息：
     - "你好"
     - "今天天气怎么样？"
     - "请介绍一下新势力企业"

2. **验证消息保存**:
   - 在Console中运行: 
     ```javascript
     window.chatStorage.getMessages().then(messages => {
         console.log('保存的消息:', messages);
     });
     ```
   - 应该能看到刚才发送的消息

3. **刷新页面测试**:
   - 按F5刷新页面
   - 等待页面完全加载
   - 检查聊天记录是否恢复显示

### 3. 窗口状态持久化测试 🆕

1. **展开状态持久化**:
   - 点击聊天助手展开窗口
   - 刷新页面（F5）
   - **期望结果**: 聊天窗口应保持展开状态，不应被自动折叠
   - **注意**: 页面加载时不应看到折叠动画闪烁

2. **折叠状态持久化**:
   - 在展开状态下点击最小化按钮
   - 刷新页面或切换页面
   - **期望结果**: 聊天助手应保持折叠状态

3. **窗口位置持久化**:
   - 拖拽聊天窗口到屏幕的其他位置（如左上角）
   - 刷新页面或切换页面
   - **期望结果**: 聊天窗口应在之前拖拽的位置出现
   - 最小化后再恢复，位置应保持不变

4. **最小化默认位置测试**:
   - 将聊天窗口拖拽到任意位置（如左上角、屏幕中央等）
   - 点击最小化按钮
   - **期望结果**: 无论当前窗口在哪里，蓝色圆形按钮都应出现在右下角默认位置

5. **重复最小化测试**:
   - 将聊天窗口拖拽到不同位置，重复进行最小化操作
   - 每次点击最小化按钮
   - **期望结果**: 每次都应该在右下角出现蓝色按钮，位置始终一致

6. **最小化状态拖拽**:
   - 将聊天窗口最小化为蓝色圆形按钮（应在右下角）
   - 拖拽蓝色按钮到其他位置（如左上角）
   - 再次展开聊天窗口，然后重新最小化
   - **期望结果**: 蓝色按钮应在上次拖拽的位置（左上角）出现，因为用户自定义了位置

7. **最小化位置持久化**:
   - 拖拽最小化按钮到自定义位置
   - 刷新页面或切换页面
   - **期望结果**: 蓝色按钮应在拖拽后的自定义位置出现

8. **脉冲动画测试**:
   - 清除浏览器存储（开发者工具 > Application > Storage > Clear All）
   - 刷新页面（首次访问状态）
   - **期望结果**: 应看到蓝色圆环的脉冲动画
   - 发送一条消息后再次清除存储并刷新
   - **期望结果**: 因为有聊天记录，不应再看到脉冲动画

### 4. 跨页面测试

1. **页面跳转测试（展开状态）**:
   - 在Shell页面中展开聊天窗口
   - 点击导航栏的不同选项跳转到其他页面
   - **期望结果**: 聊天助手应保持展开状态且记录不丢失

2. **页面跳转测试（折叠状态）**:
   - 将聊天窗口最小化
   - 切换页面
   - **期望结果**: 聊天助手应保持折叠状态

3. **多轮对话测试**:
   - 在不同页面继续发送消息
   - 验证所有消息都被正确保存和显示
   - 测试窗口状态在页面切换时是否保持一致

### 5. 存储管理测试

1. **查看存储数据**:
   - 开发工具 → Application → IndexedDB → AIChatStorage
   - 展开 `chatMessages` 和 `chatSettings` 表
   - 查看保存的消息数据和设置数据

2. **设置数据验证**:
   - 在Console中运行:
     ```javascript
     window.chatStorage.getSetting('chatExpanded').then(value => {
         console.log('窗口展开状态:', value);
     });
     
     window.chatStorage.getSetting('chatPosition').then(value => {
         console.log('展开状态位置信息:', value);
     });
     
     window.chatStorage.getSetting('minimizedPosition').then(value => {
         console.log('最小化状态位置信息:', value);
     });
     ```

3. **清除功能测试**:
   - 点击聊天窗口的"清除聊天记录"按钮
   - 验证UI清空
   - 检查IndexedDB中的数据是否也被清除
   - 验证窗口状态是否恢复为默认状态

4. **会话管理测试**:
   - 在Console中运行:
     ```javascript
     window.chatStorage.getRecentSessions().then(sessions => {
         console.log('会话列表:', sessions);
     });
     ```

### 6. 错误处理测试

1. **存储脚本缺失测试**:
   - 在开发工具Network标签中阻止`chat-storage.js`加载
   - 刷新页面
   - 确认聊天功能仍然正常，只是没有持久化

2. **IndexedDB不可用测试**:
   - 在隐私模式下打开页面
   - 验证应用的降级行为

- 页面加载无JavaScript错误
- Console显示"聊天记录持久化功能已启用"

- 跨页面导航时聊天记录保持不变

- 聊天窗口状态在页面刷新后重置为折叠状态

- 拖拽最小化按钮后的自定义位置无法保存
- 跨页面导航时聊天助手重新加载或状态丢失
- 页面跳转时AI助手出现明显延迟（超过1秒）
- 页面加载时出现不必要的折叠动画闪烁

- 发送消息时出现保存错误

## 调试指南

### 常见问题排查

1. **存储管理器未加载**:
   ```javascript
   console.log('存储管理器状态:', window.chatStorage);
   console.log('ChatStorageManager类:', window.ChatStorageManager);
   ```

2. **数据库连接问题**:
   ```javascript
   window.chatStorage.initDB().then(() => {
       console.log('数据库连接成功');
   }).catch(error => {
       console.error('数据库连接失败:', error);
   });
   ```

3. **消息保存问题**:
   ```javascript
   window.chatStorage.saveMessage('测试消息', 'user').then(() => {
       console.log('消息保存成功');
   }).catch(error => {
       console.error('消息保存失败:', error);
   });
   ```

### 手动数据操作

```javascript
// 查看所有消息
window.chatStorage.getMessages().then(console.log);

// 清除当前会话
window.chatStorage.clearSession().then(() => {
    console.log('会话已清除');
});

// 导出聊天记录
window.chatStorage.exportMessages().then(data => {
    console.log('导出数据:', data);
    // 可以保存为JSON文件
    const blob = new Blob([JSON.stringify(data, null, 2)], 
        {type: 'application/json'});
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'chat-export.json';
    a.click();
});
```
