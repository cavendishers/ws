# 地区选择器重构使用说明

## 概述

地区选择器已从基于前端请求JSON数据的方式重构为基于后端预渲染HTML的方式，提升了性能并简化了前端逻辑。

## 主要变化

### 1. 前端变化

**之前（基于JSON数据）：**
- 前端需要请求 `regions-data.json` 文件
- 在内存中构建地区数据结构
- 动态生成HTML元素

**现在（基于预渲染HTML）：**
- 前端直接从页面中获取预渲染的地区DOM
- 通过DOM查询和筛选实现三级联动
- 不再需要重建数据结构

### 2. 后端变化

**新增工具类：**
- `data_hall/utils/region_selector_utils.py` - 地区选择器辅助工具
- `RegionSelectorHelper` - 生成预渲染HTML的核心类

**新增管理命令：**
- `generate_region_template` - 从JSON生成完整的地区HTML模板

## 使用方法

### 1. 在Django视图中使用

```python
from .utils.region_selector_utils import region_selector_helper

def your_view(request):
    # 生成地区选择器的预渲染HTML
    region_dom_cache = region_selector_helper.generate_region_dom_cache()
    
    context = {
        'region_dom_cache': region_dom_cache,
        # 其他上下文数据...
    }
    
    return render(request, 'your_template.html', context)
```

### 2. 在模板中使用

```html
{% extends 'base.html' %}
{% load static %}

{% block extra_css %}
<link rel="stylesheet" href="{% static 'data_hall/css/region-selector.css' %}">
{% endblock %}

{% block content %}
<!-- 你的页面内容 -->

<!-- 地区数据DOM缓存 - 由后端预渲染 -->
{{ region_dom_cache|safe }}
{% endblock %}

{% block extra_js %}
<script src="{% static 'data_hall/js/region-selector.js' %}"></script>
<script>
// 使用地区选择器
function showRegionSelector() {
    if (window.regionSelector) {
        window.regionSelector.show([], (selectedCodes, selectedNames) => {
            console.log('选中的地区代码:', selectedCodes);
            console.log('选中的地区名称:', selectedNames);
            
            // 在这里处理选中的地区，例如：
            // - 更新页面显示
            // - 发送API请求进行筛选
            // - 更新其他组件状态
        });
    }
}
</script>
{% endblock %}
```

### 3. JavaScript API

重构后的地区选择器保持了相同的JavaScript API：

```javascript
// 显示地区选择器
window.regionSelector.show(
    ['110000', '120000'], // 预选的地区代码（可选）
    function(selectedCodes, selectedNames) {
        // 确认回调函数
        console.log('选中的地区代码:', selectedCodes);
        console.log('选中的地区名称:', selectedNames);
        
        // 处理选中的地区
        handleSelectedRegions(selectedCodes, selectedNames);
    }
);

// 获取当前选中的地区
const selectedRegions = window.regionSelector.getSelectedRegions();
const selectedNames = window.regionSelector.getSelectedRegionNames();
```

## 性能优势

### 1. 减少网络请求
- **之前**：需要单独请求 `regions-data.json` 文件（约100KB）
- **现在**：地区数据直接嵌入页面，无额外请求

### 2. 加载速度提升
- **之前**：需要等待JSON下载完成并解析
- **现在**：页面加载完成即可使用

### 3. 内存占用优化
- **之前**：需要在内存中维护完整的地区数据对象
- **现在**：直接操作DOM，内存占用更小

## 开发工具

### 生成完整地区模板

如果需要重新生成完整的地区HTML模板：

```bash
python manage.py generate_region_template --output region_template_full.html
```

生成的文件可以用于：
- 手动复制到模板文件中
- 检查数据完整性
- 调试地区数据结构

## 注意事项

### 1. 模板大小
预渲染的地区数据约19000行HTML，虽然会增加页面大小，但由于：
- 数据压缩后传输量较小
- 避免了额外的HTTP请求
- 整体性能仍有提升

### 2. 缓存策略
建议在生产环境中：
- 启用gzip压缩
- 使用CDN缓存页面
- 考虑将地区数据单独缓存

### 3. 扩展性
如果需要支持更多地区或动态地区数据：
- 可以扩展 `RegionSelectorHelper` 类
- 支持从数据库动态生成地区数据
- 支持按需加载特定地区数据

## 兼容性

重构后的地区选择器完全兼容现有的前端代码，只需要：

1. 在视图中添加 `region_dom_cache` 到上下文
2. 在模板中添加 `{{ region_dom_cache|safe }}`
3. 前端JavaScript代码无需修改
