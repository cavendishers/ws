# 三级地区选择器功能测试报告和使用说明

## 1. 功能概述

三级地区选择器是一个支持省-市-区三级联动的地区选择组件，具备文氏图包含关系逻辑、智能搜索、跳级选择等高级功能。

### 1.1 核心特性
- ✅ **三级联动**：省份 → 城市 → 区县的层级展开
- ✅ **文氏图包含关系**：父地区包含所有子地区，支持正向包含和反向优化
- ✅ **智能搜索**：支持模糊搜索省市区，自动匹配简称
- ✅ **跳级选择**：可直接选择子地区，自动补全父地区链条
- ✅ **展开状态检测**：区分正常层级选择和跳级选择
- ✅ **智能计数**：只统计最顶层的有效选择数量
- ✅ **数据导出**：支持地区代码和地区名称两种格式导出

```javascript

// 手动初始化

    initRegionSelector();
}
```

### 3.2 显示选择器

```javascript

    ['320100', '320200'], // 预选地区代码数组

        console.log('选中的地区名称:', selectedNames);
        
        // 处理选择结果

    }
);
```

### 3.5 集成示例

#### 3.5.1 与表单集成

```javascript
// HTML
<button id="region-selector-btn">选择地区</button>
<input type="hidden" id="selected-regions" name="regions" />
<div id="selected-display">未选择地区</div>

// JavaScript
document.getElementById('region-selector-btn').addEventListener('click', function() {
    const currentRegions = document.getElementById('selected-regions').value
        ? JSON.parse(document.getElementById('selected-regions').value)
        : [];
    
    window.regionSelector.show(currentRegions, function(codes, names) {
        // 保存选择结果到表单
        document.getElementById('selected-regions').value = JSON.stringify(codes);
        
        // 更新显示
        const displayText = names.length > 0 
            ? names.join(', ') 
            : '未选择地区';
        document.getElementById('selected-display').textContent = displayText;
        
        // 提交到后端
        submitRegionFilter(codes);
    });
});
```

#### 3.5.2 与Ajax筛选集成

```javascript
function submitRegionFilter(regionCodes) {
    // 构建筛选参数
    const filterParams = {
        regions: regionCodes,
        // 其他筛选条件...
    };
    
    // 发送Ajax请求
    fetch('/api/companies/filter', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'X-CSRFToken': getCsrfToken()
        },
        body: JSON.stringify(filterParams)
    })
    .then(response => response.json())
    .then(data => {
        // 更新页面显示
        updateCompanyList(data.companies);
        updateFilterStatus(data.total_count);
    })
    .catch(error => {
        console.error('筛选请求失败:', error);
    });
}
```

#### 3.5.3 后端接收处理

```python
# Django视图示例
def filter_companies(request):
    if request.method == 'POST':
        data = json.loads(request.body)
        region_codes = data.get('regions', [])
        
        # 构建筛选查询
        if region_codes:
            # 方式1：精确匹配
            companies = CompanyInfo.objects.filter(
                region_code__in=region_codes
            )
            
            # 方式2：层级匹配（如果需要包含子地区）
            companies = CompanyInfo.objects.filter(
                Q(region_code__in=region_codes) |
                Q(region_code__startswith=region_codes[0][:2])  # 省级匹配
            )
        else:
            companies = CompanyInfo.objects.all()
        
        return JsonResponse({
            'companies': list(companies.values()),
            'total_count': companies.count()
        })
```

## 4. 技术特点

### 4.1 文氏图包含关系
- **正向包含**：选择父地区自动包含所有子地区
- **反向优化**：选择所有子地区自动合并为父地区
- **跳级补全**：直接选择子地区自动补全父地区链条

### 4.2 智能展开状态检测
- **层级选择**：在展开状态下选择子地区，不触发反向选择
- **跳级选择**：直接搜索选择子地区，触发父地区补全
- **状态隔离**：确保不同选择方式的逻辑隔离

### 4.3 性能优化
- **DOM缓存**：预加载所有地区数据到内存
- **事件委托**：高效的事件绑定机制
- **智能更新**：只更新变化的DOM元素

## 5. 注意事项

### 5.1 数据格式要求
- 地区代码必须遵循国标编码规范
- DOM缓存必须包含完整的三级地区数据
- 数据结构需要包含`data-code`、`data-name`、`data-type`、`data-parent`属性

### 5.2 兼容性说明
- 支持现代浏览器（Chrome 60+, Firefox 55+, Safari 12+）
- 依赖ES6特性（Set, Map, 箭头函数等）
- 需要CSS Grid和Flexbox支持

### 5.3 错误处理
- 自动检测数据缺失并显示友好提示
- 防止重复初始化和内存泄漏
- 提供详细的控制台日志用于调试
